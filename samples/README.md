# DietSense Sample Test Assets

This folder contains high-resolution sample assets for testing DietSense's offline grocery bill scanner and fridge snapshot vision processor.

## Available Sample Files:

1. **`blinkit_sample_bill.png`**:
   - Realistic Indian quick-commerce grocery receipt (Paneer, Palak, Dahi, Bread, Milk, Tomatoes, Moong Dal, Oats).
   - Ideal for testing receipt parsing and OCR fallback.

2. **`blinkit_sample_bill.pdf`**:
   - PDF format invoice for testing PDF text & table extraction.

3. **`fridge_sample_snapshot.png`**:
   - Refrigerator shelf snapshot with dairy, greens, protein, and staples.
   - Ideal for testing fridge vision scanning and pantry auto-stocking.

## How to Test:
- Upload or drag & drop any of these files into the **Pantry / Scanner** tab in the web app.
- Or click the **'⚡ Scan Sample Blinkit Bill'** or **'📸 Scan Fridge Photo'** preset buttons directly in the UI.
