1. Why Local SQLite instead of Cloud DB?

          

            Complete privacy, zero cloud hosting bills, zero network latency, and 100% offline functionality. SQLite with WAL mode supports concurrent reads and fast transactions for local workloads.
          

        


        

          
2. How is Multi-Tenant Isolation Enforced?

          

            Every table referencing user data has a foreign key to users.id with ON DELETE CASCADE. FastAPI derives user_id exclusively from the verified JWT token on every query.
          

        


        

          
3. Where Do Nutrition Numbers Come From?

          

            Strictly from the foods table (14,181 rows from USDA & ICMR-NIN). The recommendation engine scores and ranks them deterministically; an LLM never touches calorie or macro values.
